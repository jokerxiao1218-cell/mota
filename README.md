# 魔塔 50 层(Pygame 复刻)

经典《魔塔 50 层》(TSW 汉化版)的 Python + Pygame 复刻:数值、地图、事件、机关
全部 1:1 来自原版数据(tacthgin 仓库提取,已按 4 个独立复刻交叉校正),像素贴图
运行时自绘,零外部素材。

玩法一句话:爬 50 层塔,杀怪/拿钥匙/开门/买属性,数值成长规划对了才打得过——
打不过的怪撞上去会直接拒绝移动(不亏血),一切以怪物手册的预测为准。

## 快速开始

```bash
./run.sh          # 玩(自动用项目自带 venv,屏蔽系统 PYTHONPATH 污染)
./test.sh         # 跑全部 187 个单元测试
env -u PYTHONPATH SDL_VIDEODRIVER=dummy .venv/bin/python scripts/walkthrough.py
                  # 全塔无头走查(见下)
```

依赖:Python 3.10+、pygame(项目 `.venv` 已装好;自装用 `pip install pygame`)。

## 按键

| 键 | 作用 |
|---|---|
| 方向键 / WASD | 走格子(撞怪=自动战斗,撞门=开/撞) |
| 空格 / 回车 | 推进对话、确认菜单 |
| ↑↓ / W,S | 移动菜单光标;数字键 1-9 直达选项 |
| H | 怪物手册(看属性+预测损血/回合——打不打得过先查这里) |
| T | 使用主动道具(飞行魔杖、冰冻魔法、怪物手册等) |
| Esc | 系统菜单(存档/读档/退出) |

存档:三槽,`save/save_1.json` 起;拿到怪物手册之前不允许存档(原版设定)。

## 全塔无头走查(scripts/walkthrough.py)

验收用的自动化"通关":真实引擎+真实数据+真实规则,从序章被夺装备一路走到
50 层击杀真魔王进结局画面,一步一格真实地走(BFS 找路、撞怪真打、机关真触发)。
唯一作弊是序章后给勇士数值加成(100000/2000/1000+钥匙若干)——它验的是
**全塔流程连通性与机关正确性**,平衡性手感归人工玩(见设计文档 §8 清单)。

刚才一次完整跑:0.2 秒(约 3000 步移动、20 个事件、105 场战斗),
退出码 0=通关、1=卡住并报告卡在哪层哪格。

## 架构(四层,详见《魔塔50层-设计文档.md》)

```
game/
  data/      JSON 数据(51 层地图/33 怪/道具/NPC/事件,转换自原版)
  core/      纯函数规则:战斗、拾取、特殊机制、存档——零 pygame,可独立测试
  events.py  事件解释器:17 种动作 + NPC/祭坛流程(intent/feed 协议,零 pygame)
  engine.py  pygame 引擎:主循环/渲染/输入,适配器调用上面两层
  ui.py      状态栏/对话/手册/菜单
scripts/
  convert_tacthgin.py   原版数据 → JSON 转换器(勘误都在注释里)
  walkthrough.py        全塔无头走查(验收工具)
tests/       187 个测试(pytest,无头可跑:数据/核心/事件/引擎)
save/        存档目录
```

状态(state)是纯 JSON 字典,存档=整包快照;每层地图格是"叠放栈"
(墙门下可能压着道具,开门后弹出来——原版机制)。
